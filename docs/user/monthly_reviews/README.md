# Monthly Reviews

Ежемесячные обзоры хранятся в формате `YYYY-MM.md`.

## Когда создавать

- В конце календарного месяца
- После завершения мезоцикла
- Перед переходом к `/next-cycle`
- Если нужно оценить, продолжать набор, перейти на поддержку или сделать мини-сушку
