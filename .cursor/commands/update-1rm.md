# Команда: /update-1rm

Обновление силовых максимумов и рабочих ориентиров.

## Описание

Команда обновляет силовые показатели после теста максимума, нового лучшего рабочего сета или заметного прогресса в повторениях.

## Источники данных

- `.cursor/project/user_profile.md`
- `docs/user/strength_records.md`
- `docs/user/workout_log.md`
- `docs/user/current_program.md`
- `docs/user/data/strength_records.json` если доступен

## Процесс

1. Определить упражнение и новый результат
2. Проверить тип результата: тестовый 1RM, расчётный 1RM или лучший рабочий сет
3. Рассчитать 1RM по формуле Эпли, если это рабочий сет
4. Сравнить с текущими рекордами
5. Предложить обновление силовых ориентиров и рабочих весов
6. После подтверждения обновить `docs/user/strength_records.md`, профиль, структурированные данные и dashboard

## Формула

```
1RM = вес × (1 + повторения / 30)
```

## Permission gates

Обновление рекорда можно записать по явному отчёту пользователя. Изменение рабочих весов в программе требует отдельного подтверждения.

## Результат

- Новый рекорд или лучший рабочий сет записан в `docs/user/strength_records.md`
- При необходимости обновлены `.cursor/project/user_profile.md`, `docs/user/current_program.md` и `docs/user/dashboard.html`
- Пользователь получает рекомендацию: закрепить вес, повысить вес или прогрессировать повторениями
