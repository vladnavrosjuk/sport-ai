# Команда: /quick-profile

Быстрое создание минимального профиля пользователя.

## Описание

Команда создаёт минимальный профиль, достаточный для первичных рекомендаций. Используется, если пользователь не хочет проходить полный `/fitness-init`.

## Минимальные данные

- Имя
- Возраст
- Пол
- Рост
- Вес
- Основная цель
- Тренировочный опыт
- Дней тренировок в неделю
- Доступное оборудование
- Травмы и ограничения
- Пищевые ограничения

## Процесс

1. Задать короткий список вопросов
2. Проверить разумность значений
3. Создать `.cursor/project/user_profile.md`
4. Отметить профиль как неполный
5. Предложить дополнить профиль через `/fitness-init`

## Результат

Создаётся профиль, после чего доступны:

- `/generate-workout`
- `/generate-nutrition`
- `/generate-full`

## Ограничения

Если не хватает данных о травмах, оборудовании или цели, не генерировать программу до уточнения.
