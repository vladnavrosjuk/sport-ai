# Команда: /generate-full

Полная генерация тренировочной программы и плана питания.

## Описание

Команда объединяет `/generate-workout` и `/generate-nutrition` в один workflow. Используется после `/fitness-init`, при старте нового цикла или при существенном изменении цели.

## Требования

- Должен существовать файл `.cursor/project/user_profile.md`
- Перед генерацией проверить актуальность веса, цели, тренировочных дней, оборудования и ограничений
- Если данные устарели или противоречивы, сначала уточнить их у пользователя

## Процесс

1. **Проверка профиля** — вес, цель, ограничения, расписание, оборудование
2. **Проверка текущих файлов** — `docs/user/current_program.md`, `docs/user/nutrition_plan.md`, логи и dashboard
3. **Генерация программы** — сплит, объём, упражнения, рабочие веса, правила прогрессии
4. **Генерация питания** — калории, белки/жиры/углеводы, распределение по дням
5. **Синхронизация** — обновить профильные ссылки, структурированные данные и `docs/user/dashboard.html`

## Permission gates

Без явного согласия пользователя не менять:

- Рабочие веса
- Калории и макросы
- Структуру программы
- Упражнения
- Тренировочные дни
- Ограничения и цели

## Результат

Обновляются или создаются:

- `docs/user/current_program.md`
- `docs/user/nutrition_plan.md`
- `docs/user/dashboard.html`
- при необходимости `docs/user/data/*.json`

После обновления dashboard напомнить пользователю сделать `git push` для GitHub Pages.
