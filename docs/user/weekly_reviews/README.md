# Weekly Reviews

Еженедельные обзоры хранятся в формате `YYYY-WXX.md`.

## Когда создавать

- После недельного отчёта по тренировкам, весу или питанию
- Перед изменением калорийности
- Перед повышением рабочих весов по нескольким упражнениям
- При заметной усталости, боли или серии пропусков

## Шаблон файла

```markdown
# Еженедельный обзор — YYYY-WXX

> Период: YYYY-MM-DD — YYYY-MM-DD
> Фаза: [мезоцикл / неделя]
```
