# Agents

Эта папка содержит явные реализации агентов проекта. Агент связывает роль, команды Cursor, project skills, rules и пользовательские файлы в один рабочий контракт.

## Доступные агенты

- [`fitness-coach`](fitness-coach/AGENT.md) — персональный тренер и нутрициолог для силовых тренировок, питания, прогресса и синхронизации dashboard.

## Формат агента

Каждый агент может содержать:

- `AGENT.md` — человекочитаемое описание роли, workflow, разрешений и источников данных.
- `manifest.json` — машинно-читаемая карта команд, правил, skills и файлов.
- Дополнительные reference-файлы или scripts, если workflow станет сложнее.
